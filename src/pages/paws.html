Design requirements

Easy to use

Anyone can find a pet in a few taps. No manuals, no jargon.

Reliable

Tested, and honest about what it knows. No invented pet facts.

Free, or nearly free

Runs at almost zero cost, so a shelter could actually afford it.

Fast and flexible

Quick to load, and easy to extend to new shelters and new data.

The Architecture

From an Instagram post to an approved pet. The AI only drafts; a person approves before anything is saved.

  • Staff side · dashboard
  • SOURCEInstagramThe shelter's public posts, brought in through the staff dashboard.
  • DASHBOARDStaff dashboardStaff paste a link, review the draft, fix it and press Accept.
  • API · STEPClean + guardStrips noise from the caption before the AI reads it.
  • API · ONE AI CALLExtractorA fixed pipeline, not an agent: the AI fills the card, allowed values are checked. It only returns a draft.
  • API · STAFF ONLYStaff routesAfter Accept, a separate call saves the pet. Photos are centre-cropped and saved here.
  • Adopter side · app
  • APPAdopter appA short quiz, then ranked matches. React + Vite PWA.
  • API · NO AIMatcherFixed rules: filter, score, rank, explain. An optional wording call to the AI is off by default.
  • Shared
  • API · ON RENDERFastAPIOne service, Python modules inside. Staff writes need a token; adopter reads are open and rate limited.
  • AI PROVIDERLLM providerAny OpenAI-compatible API running gpt-oss-20b. OpenRouter in production, Groq by default.
  • DATASupabasePostgreSQL for the pets, storage for the photos.
  • PLANNEDLangfuseTraces and cost for every AI call.
  • PLANNED · MAINTAINER TOOLSClaude Code on my laptopFour read-only helpers: caption-fetcher, card-drafter, extraction-reviewer, ranking-auditor (optional). None can save; you approve each card.
  • Evaluation
  • EXTRACTION EVALUATIONChecks the ExtractorStaff also review every draft by default. On demand, the 25 posts labelled by staff are replayed through the real extractor with real AI calls, and each field is scored.
  • RANKING EVALUATION · NO AIChecks the MatcherStaff answers (yes, maybe, no) are compared with our top 5, plus safety checks. Runs with the tests. See The Evaluator below.

Source code is private.

The Matcher

Filter, score, then order. No AI in any of the three steps.

  • Pet listEvery pet in the shelter.
  • FIXED RULESHard filtersPass or fail. Pets that cannot work for this home are hidden.
  • FIXED RULESFit score0 to 100% compatibility, each with its reasons.
  • FIXED RULESPriority rankingHarder-to-place pets move up. The percentage itself never changes.

The Evaluator

How we check the ranking is good. Staff say what is right, plain code compares. No AI.

  • A PERSONStaff answerStaff say yes, maybe or no for each pet, for a few typical adopters.
  • NO AIMatcher ranksThe Matcher ranks the same pets for the same adopter. It never sees the staff answers.
  • RESULTCompareExample: staff agree with 4 of our top 5. The one they do not is where we look first.
  • NO AISafety checksThousands of imaginary adopters catch rule breaks, like a ruled-out pet being shown.
