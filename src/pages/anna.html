ANNa

Anti-Leukemia Neural Network

Final project at IronHack: a U-Net plus a binary classifier that labels cells as leukemia blasts or healthy.

Acute lymphoblastic leukemia represents 25% of all pediatric cancers.

Honest read

ANNa recognizes the diseased cells but has difficulty with the healthy ones. The results agree with those reported on Kaggle.

Data note

The training set is imbalanced: almost twice as many positive as negative samples.
