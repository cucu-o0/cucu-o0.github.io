# Vero's Portfolio

Live at [cucu-o0.github.io](https://cucu-o0.github.io). See [EDITING.md](EDITING.md) for how to change the content.

## Run locally

```bash
npm install
npm run build        # writes dist/
npx serve dist       # or: python3 -m http.server -d dist 8000
```

Every push to `master` builds and publishes the site with GitHub Actions.
